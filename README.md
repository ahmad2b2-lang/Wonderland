# Wonderland

An illustrated picture-book web game: Amoona follows a rabbit through a glowing cave into Wonderland.

- 15 story pages in **English and Arabic** (switch with the language button)
- Background music that changes when the story enters Wonderland, plus magic sound effects
- A treasure chest at the end that opens to reveal where the real treasure box is hidden

## Play

Open `index.html` in a browser. Everything (pictures, music, code) is inside that one file.

The treasure page shows `photo1.jpg`, which must sit in the same folder as `index.html`.
